# STL files

このディレクトリの STL ファイルは、toio Core Cube を使ったペンプロッター用の 3D プリント部品です。

## Files

- `cube-holder.stl`: toio Core Cube を保持する部品
- `pen-holder.stl`: ペンを保持する部品
- `stopper.stl`: 補助用のストッパー部品
